Sudoku brief · new Adaptation logic · page 1 · the plan

Adaptation proposes 14 normal workflows, start to end. J2 numbers them in the order they will run, so W-1 is the first on the map.

The logic

  • Identity writes the charter. Adaptation plans with realization (factors, stages) and certainty (five gates, zone).
  • The judge asks the same question of every workflow: can it make its output? Code sets the score. Pass line 0.80.
  • Adaptation proposes all workflows in dependency order. J2 registers them as W-1, W-2, … in that order.
  • Each workflow has one output, an artifact (a .md, .json or part of index.html). Later workflows read it.
  • The map shows a workflow when it is the next to run. Audit findings give birth to fix workflows.

Code changes needed?

  • For this PDF: none. It is a model of the run, built from last night's plan and timings.
  • For W-1 to be the first workflow on the map: none. The validator gives ids in proposal order, and Coordination runs the lowest ready id first.
  • To run it for real: yes, one change in Adaptation. Today, W-1 to W-5 are written in a separate step (decisions.md) and never become J2 workflows. That step must go, and all judged workflows must go to J2. No change is made yet.
