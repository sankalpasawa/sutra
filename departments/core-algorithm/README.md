The attached `lab/` (its build label is at the top of `lab/README.md`) is a deterministic Python reference with human-authored synthetic extension packs. It is **not** Sutra Core `v0.2.2`, `v0.3.0-CANDIDATE`, production J2, or an installed Native capability. Those historical streams must not be merged by naming alone.

## Boundaries

- New business semantics are sourced/approved extension content, not implicit facts generated by recursion.
- The solver proposes and locally tests. It cannot mint its own external grants, promote Methods, assert real-world completion or replace trusted validators.
- A simulated action receipt is **LOCAL_MODEL_ONLY**, not a delivery, CRM write, or production installation.
- Four linked interpretations—World, Knowledge, Design and Run—must not be conflated.
- Native canon lives in [`os/engines/NATIVE-ENGINE.md`](../../os/engines/NATIVE-ENGINE.md) and its ADRs. This department is not a ratification or amendment of that canon.
