# Vendored J2 engine

Source: the J2 prototype as it is kept in this repository's own copy `prototypes/j2`, at the sutra commit `00efb179e21cb79fae157a0679e819921ac37726` (tree of `prototypes/j2`: `99b6f3a05de78a609b593d81d7fb06b55c32b961`), extracted with `git archive 00efb179e21cb79fae157a0679e819921ac37726 prototypes/j2 | tar -x --strip-components=2 -C <empty folder>` (sync 4, D136). That extraction, given to the script with `--source` and `--commit`, is the only source of every file below, never the working tree. History, not a source: the earlier syncs took the J2 prototype at the commits `9200cf6` and `33aeeda`; the design documents cite the line numbers (`j2.py:n`) of `ce2631f`, and everything after `j2.py:8313` has moved. Patches are located by anchor text, never by line.

Copied into `sutra_app/engine/` with the same module names; every change to a J2 file is one of the numbered patches below and nothing else (decision D13). Prompts stay byte-identical. There is no P6 (the design's table skips it) and no P13 (retired in sync 4, D140: its code is Sutra's own `engine/runlist.py`). This file is written by `scripts/vendor_j2.py`; `scripts/py scripts/vendor_j2.py --source <the extraction> --commit 00efb179e21cb79fae157a0679e819921ac37726 --check` re-derives every file below from the J2 source and fails on any difference.
