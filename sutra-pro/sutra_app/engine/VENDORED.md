The design was written against `ce2631f`; its line numbers (`j2.py:n`) are that commit's, and everything after `j2.py:8313` moved down by 7 lines. Patches are located by anchor text, never by line.

Copied into `sutra_app/engine/` with the same module names; every change to a J2 file is one of the numbered patches below and nothing else (decision D13). Prompts stay byte-identical. This file is written by `scripts/vendor_j2.py`; `scripts/py scripts/vendor_j2.py --source <J2 checkout> --check` re-derives every file below from the J2 commit and fails on any difference.
