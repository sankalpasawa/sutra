# Vendored J2 engine

Source: the J2 prototype as it is kept in this repository's own copy `prototypes/j2`, at the sutra commit `1adb8ecd8fa8eef47fb7a0fc63a1616f556cdfeb` (tree of `prototypes/j2`: `9a7cb34c028248de7d3b436647f8baf39be6f77e`, J2's main, not tagged), extracted with `git archive 1adb8ecd8fa8eef47fb7a0fc63a1616f556cdfeb prototypes/j2 | tar -x --strip-components=2 -C <empty folder>` (sync 6, D176). That extraction, given to the script with `--source` and `--commit`, is the only source of every file below, never the working tree. History, not a source: the earlier syncs took the J2 prototype at the commits `9200cf6` and `33aeeda` and `025e265c` (sync 4) and `1d537295` (sync 5, the tag `cut-off/2026-11-12`); the design documents cite the line numbers (`j2.py:n`) of `ce2631f`, and everything after `j2.py:8313` has moved. Patches are located by anchor text, never by line.

Copied into `sutra_app/engine/` with the same module names; every change to a J2 file is one of the numbered patches below and nothing else (decision D13). Prompts stay byte-identical. There is no P6 (the design's table skips it) and no P13 (retired in sync 4, D140: its code is Sutra's own `engine/runlist.py`); P20 is reserved for a late-judge switch (D145, D162, D180). Sync 5 (D160 to D163): the pin moved to the tag `cut-off/2026-11-12`; the types are vendored as data (`conditions/` and `templates/` as whole trees, D161); P1 is a counted rule, P7, P8, P9, P12 and P14 were repaired, P2 gained a third edit, P17 and P18 are new (D162). Sync 6 (D176 to D181): the pin moved to J2 main `1adb8ecd` (J2 has not tagged it; the tag name is added when it does); the seven commits labelled "needs owner review" (run templates, auto-reuse) are carried inert behind `J2_RUN_TEMPLATES` and `J2_AUTO_REUSE`; P1 (15 lines in `j2.py`, one in the new `j2_artifact_lib.py`, 41 in all), P7, P8 and P9 were re-anchored, P10 covers two more writers of the library index, P19 is new (the reviewer switch).
