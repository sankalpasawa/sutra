### What is new in 0.7.0

- **Four new features, all switched off.** Projects (a request that Sutra splits into steps that run one after the other), Ask (read-only answers about your folder with the files they came from), a Work list of everything Sutra did, and Recipes (a way of working you save and start again). Each is **off unless you turn it on** with its own setting (`SUTRA_NODES_V1`, `SUTRA_ASK_V1`, `SUTRA_WORK_V1`, `SUTRA_RECIPES_V1`, all `0` by default). Nothing in the app changes for you if you do nothing.
- **Projects are for a read-only trial.** One real run, with Claude building and Codex checking, went from a request to Done on a small read-only folder and cost about $3. Several paths have not been tried with a real model: asking for changes and sending a step back, answering a team's own question from the project page, Decide for me on a project, steps that run at the same time, steps that change your folder, Windows, the first-time permission window on a Mac. Try Projects on a throw-away folder with a low dollar limit, and read `docs/OPERATIONS.md` first.
- **Your data is upgraded once.** The first start of 0.7.0 moves your data to a newer version (schema 8) and first saves a copy, `pre-upgrade-v<old>-to-v8.sqlite3`, next to it. **An older version of the app cannot open a database that 0.7.0 has upgraded**: keep that copy, or run `sutra-pro backup --to <folder>` first, if you may want to go back.
