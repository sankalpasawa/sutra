### What is new in 0.6.2

- **Builders can use tools while they work.** With the Claude command-line tool installed and signed in, a team's builders write and run files in their own folder; on a Mac or Linux with the sandbox runtime installed, they work inside a sandbox.
- **Running a script on your own folder is safer.** A test run never touches your real folders, and the real run happens only after you approve it.
- **Fewer stuck plans.** When a step that runs on your files clashes with another step, the team is told which one to change. If the same plan is refused twice in a row, the team stops and asks you instead of trying again.
- **Only finished work is reused.** A run that ended with open items is no longer saved as a template or copied into a new run.
- **A new Windows icon.** The Windows app has its own woven-lotus icon.
