### What is new in 0.9.0

- **Give a file where you start work.** The box that says "What should we make?" (and the box under it once work began) now has a paperclip. Drop a spec, a CSV or a Word file on it, or paste a screenshot, and the team is given the file: it is copied into the run's folder and its opening is in the team's notes. A file the app cannot take stays as a red "not attached" line with the reason, and Go waits until you remove it. The same paperclip is on Attention's box and on "Tell the team" in a project's chat. "Files go only to the model" is gone.
- **A project keeps its files.** Open "Project files and memory" from the project's name. Add files once, switch each on or off for the project, rename or remove them, and every run and every chat of that project can read them. Small files go in whole; a long set is searched for the parts that match each message. "Add to project" on any file you attached keeps it there. Excel and PowerPoint files are still not read; PDFs and images are kept for reference only. Nothing leaves your computer except to the model you choose, when a chat or run uses it, and the panel shows exactly what would be sent.
- **A project remembers.** Write the project's instructions once. When a run ends or you archive a chat, one short line is kept (what you asked, how it ended); a new chat or run starts with the newest lines. You can read, edit, add, delete or turn off any line, or the whole memory. Existing projects start with their last ten runs and last five archived chats. No model writes these lines.
- **Create project takes files.** Drop files in the box and they are added once the project exists. If one cannot be added, the project is still made and the box says which file failed.
- **Not in this release.** Files with a "Let Sutra choose" request are read by the planner and given to each team it starts, but a file inside an answer to a team's question, and files on a project started from the API, wait for a later release; an answer with a file is refused with a sentence, never dropped.
- **Not tried yet in the desktop app:** checked through the server, the page code and the tests, not by dropping files into a packaged beta. No real model was called.
