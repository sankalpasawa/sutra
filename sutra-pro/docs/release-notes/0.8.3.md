### What is new in 0.8.3

- **A file you attach is read, or you are told why not.** A file the app cannot take (a type it refuses, or one over 20 MB) now stays on the box as a red "not attached" line with the reason, and Send waits until you remove it. Before, the note vanished with your next keystroke and the message went without the file.
- **The file bar is always visible.** It shows under "Tell the team" as well. A message to the team cannot carry a file, so Send tells you: "Files go only to the model. Remove them, or ask the model." Nothing is dropped quietly.
- **You see what the model received.** Under your message: "Read: notes.txt (all 12,000 characters)", "Read: big.csv (first 40,000 of 90,000 characters)" or "Sent as an image: shot.png". A message the model cannot take (a PDF on Codex) is refused before it is stored, and your words stay in the box.
- **Word files work.** `.docx` is read as text. Many more text and code types are taken too, and so are text files saved by Excel or Notepad in another encoding. Files that usually hold secrets (`.env`, keys, `credentials`) are still refused. Excel and PowerPoint files are refused with a sentence that says to save them as CSV or PDF.
- **The model remembers a file for the rest of the chat.** If a chat starts a new model session (you change the working folder, switch between Claude and Codex, or the session is lost), the text of files you attached earlier goes along with the history, up to 30,000 characters in all.
- **Not tried yet in the desktop app:** these were checked through the server and the tests, not by dropping files into a packaged app. No real model was called.
