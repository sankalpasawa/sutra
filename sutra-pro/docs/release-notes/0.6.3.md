### What is new in 0.6.3

- **Check for updates works again on Windows.** Since GitHub changed its certificates in late October, the check could fail with "Could not reach GitHub" on some Windows PCs, and once it failed it kept failing until the app was restarted. The check now accepts a certificate chain that ends in a certificate your Windows already trusts. The chain is still verified and the name still checked.
- **A Budget field on the start page and the home screen.** It starts empty ("team default"). A cap applies only when one is set, and every raise is your own.
- **Priority's moves are checked.** When Priority moves a workflow, the move names the workflow and its envelope; a move the budget cannot cover is rejected with a reason.
