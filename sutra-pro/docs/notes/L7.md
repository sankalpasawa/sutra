## Deviations
- Every string and list is bounded (rule 3; the transport schema strips bounds, so shas hold). Models have no class docstring
  (pydantic copies it into the schema).
- `RuleSpec.rule` is a Literal, but an unknown type is a `value_error` in J2's words (before-validator), as the design table says.
  One spec reports `rule (enum): ...`, a list `rule 3 (enum): ...`; `spec_problems` is the one source of the wording.
- `run_specs` takes `RuleSpec` or J2 dicts; anything else is reported as unknown (J2 raised). No shipped rule uses `ids_unique`.
- `Template` is frozen (sha and version change by `evolve`). `content()` writes rules as J2 dicts, so every sha equals J2's. A stored
  sha is not checked against the content.
- `build_model` classes derive from strict `Value` (J2: lax); cache key = computed sha (a stale stored sha must not find another
  class), 256 entries. A one-value enum stays a constraint in the transport schema (L1's const change; J2 dropped it).
- Left to the engine as designed: router, library I/O (`store`, `get`, `mark_used`, `save_into_run`, `run_templates`), codegen,
  prompts. Here: `run_tpl_rel` and the models of the J2 sync files.

## Decisions
- J2 sync models: `TemplateMeta` (meta.json: kind generic/specialised, used_by, `class` via alias), `TemplateDecision` (optional
  `saved`, checked against `templates/<artifact>/<slug>/<slug>@v<N>`), `RunTemplate` (adds `source`), `TemplatesFile`; payloads
  `template.meta|decision|run|file`. The `"schema": "template-library/1"` key is checked, not stored (a field `schema` needs a
  non-keyword alias; rule 7 allows that only for AtomView); `to_json()` puts it back first.
- `validate`, `errors_of`, `normalise` live in `render.py`; `write_generic`/`generic_drift` take a root (default
  `SUTRA_TEMPLATES_DIR`, else `docs/schemas/templates`).
## Known limits
- At most 5000 uses per version, 60 fields (25 by the check), 2000 decisions per templates.json. The drift test for
  `docs/schemas/templates` asserts only once that directory exists (L8 owns `docs/schemas/`).
