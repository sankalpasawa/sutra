## Deviations from the design

1. **The studio.** The table of 28 edits is not the truth any more (the addendum says so): see the table above. Five edits are new (E2c, E20g, E20h, E20i, E23) and E5 and E19 moved.
   The strip class is `steamstrip`, not `shome`, so lane E2's `#sview>.shome` rule becomes `#sview>.steamstrip`.
2. **E20g is a relative link** (`library?view=detail`), because markup cannot hold the team; it resolves to `/d/<id>/library` from `/d/<id>/` and from the library page, and to J2's own
   `/library` at J2's root.
3. **`j2-shell.css` does not name the previous commit** in its first line (the owner took that source out); it says "as it was ported before sync 4".
4. **Three tests outside my file list were touched** because the freeze and the new sheet moved them: `test_home.py` (Home's sheet name), `motion_css.test.js` (the frozen set; the record of J2's
   motion), `test_serve.py` (the two tests that list the route set).
5. **The preview frames keep the sandbox (D83)**, as the coordinator decided. J2's studio reads the frames' documents (`sDoc`, `sFrameSetup`, `sDecorate`: tags on parts, glow on a new
   version, scroll restore across versions, link interception); under the sandbox and the engine's sandbox header they cannot be read, so those features are off. The code is guarded, the
   frames still show the output, and the list goes to "not taken" in the sync note.

## Left, and notes for others

- The first-paint theme of J2's new page defaults to **light**; Home's default is dark. A viewer who never chose gets two looks. Not changed (J2's design); a one-line edit if the owner wants Home's default.
- `role="tab"` buttons sit in the rail strip outside a `tablist` (as designed); J2's own pool of tabs is inside one. The page's focus order and labels are right; an ARIA audit may ask for a wrapper.
- The console draws ten `hu*`/`nwait`/`nylane` classes (heads-up view) that only `sutra-shell.css` styles, which the console does not load: found by `test_shared_css.py`, older than the
  freeze, listed there as known.
- `tests/ui/fake_backend.py` run by hand as a script stops with a `NameError` (`register_agent_chats` is defined below the `__main__` block); imported as a module it runs.
  Lane E3b owns it.
- `/doc/<kind>`, `/view?name=`, `/api/record`, `/api/settings` and `state.decide_for_me` are lane B's and E3b's fake's; the page needs them for the studio's output tabs, the record drawer and
  Decide for me.
