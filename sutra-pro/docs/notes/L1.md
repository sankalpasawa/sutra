# L1 as built: foundations, registry, gate, replies, export, id helpers

Built, as library.md sections 3.1 to 3.6 and 14 say: `types.py` (scalars, id patterns, `Violation`, `DomainEvent`,
`atom_sid` / `function_atom_id` / `overhead_atom_id` / `function_node_id`), `base.py` (`Value`, `Record`, `canonical_json`),
`registry.py` (`ModelRegistry`, `REGISTRY`, `record`, `transport_schema`, `reply_schema`, `is_transport_safe`),
`gate.py` (`Gate`, `GATE`, `Checked`, `GateError`, the four shipped cross rules), `replies.py` (`ReplyParser`,
`extract_json` / `close_json` from J2, the fence search made linear in review round 1), `export.py`. `__init__.py` is a
docstring. 6 test files, 444 tests, 3 s (after review round 1: see the end).
`transport_schema`, `reply_schema` and `schema_sha` equal J2's byte for byte on J2's 19 section models (checked in a
scratch run with J2's `OPTIONAL_FIELDS` as the optional set); a prototype of the L2 chart classes gives a 2.25 KB schema.

## Deviations from the specification
- `Value` config adds `allow_inf_nan=False` (canonical JSON must be JSON). `evolve` and `canonical_json` live on `Value`
  so payloads have them too (the spec put them on `Record`).
- Id patterns use `[0-9]`, not `\d` (ASCII only) and are matched with `fullmatch`; `WorkflowId` and `AtomId` carry a
  max_length because their digit runs are unbounded. `EdgeId` had no pattern: `<kind>:<from>><to>`, no whitespace.
- `Violation.path` <= 500 and `code` <= 80 (the spec bounds only `message`); `violation()` clips instead of failing.
  Messages lose pydantic's "Value error, " prefix; a payload with over 50 errors reports 50 plus one `more_errors`.
- `JsonObject` is bounded: 500 top-level keys, 32 levels, finite numbers.
- `retry_text` leaves out ": " when the path is empty and is cut at 4000 characters.
- `verify_refs(specs=None, *, check_arity=None)`: L1 cannot import `FunctionSpecs` or `CheckTemplate`, so it takes them
  by argument or from `bind_function_specs` / `bind_check_arity` (the reply-family part needs only the registry). Since
  round 1 it raises when it has nothing to check instead of returning `[]`.
- Rules 3 and 7 (every str and list bounded; aliases only for Python keywords) are not enforced when a class is declared
  (`AtomView` needs an alias for `schema`); since round 1 `unbounded_fields` and `aliased_fields` check a class.

## Decisions
- A payload is a family with one pseudo-kind, its own name (`kinds`, `index.json`, `Checked.kind`). Payload families are
  never auto-upgraded by the gate; `upgrade_payload` is there for the caller.
- `Gate.check` turns every dict into JSON text first, so the text it validates is the text the store keeps. Order of
  refusals: unknown, size (judged before the text is decoded), shape, cross, round_trip. Older `schema_version` runs the
  chain (the registry sets each step's version); a data error inside an upgrade is `shape` / `upgrade_failed`.
- Shipped rules read plain attributes (`supersedes`, `from_id`, `department_id`, `nodes`); codes: `unknown_atom`,
  `supersedes_not_abandoned`, `unknown_node`, `unknown_department`, `not_a_department`, `no_chart`, `department_not_in_chart`.
- `ReplyParser`: a whole-text JSON object wins over `extract_json`; valid JSON that is not an object is `not_object`;
  a family with several classes is told apart by the reply's own `kind` (any case); keys dropped and enum words fixed are
  reported as dotted paths. Unknown family or kind is a `RegistryError`, not a `ReplyInvalid`.
- `transport_schema`: each class's `TRANSPORT_OPTIONAL` applies to that class's own properties only (round 1; it was the
  union over the whole tree applied by name, J2's global set). An enum gains `null` when its folded type allows null.
- `freeze()` refuses an upgrade that leads to no registered version (`dangling_upgrade`). `export` removes only stale
  top-level `<family>.v<N>.json` files, writes under `SUTRA_SCHEMA_DIR` / `--dir` / `docs/schemas`, creates nothing else.

## Known limits
- `Optional[$ref]` and `Optional[union]` lose their null in the transport schema, as in J2 (keeps J2's shas); mark such
  fields in `TRANSPORT_OPTIONAL`. `atom_sid("a:b","c")` equals `atom_sid("a","b:c")`: no real run or node id holds a colon.

## Follow-ups for other packages
- L4/L6/L10: bind `REGISTRY.bind_function_specs(load_function_specs)` and `bind_check_arity(...)` at import:
  `REGISTRY.verify_refs()` raises until both are bound (round 1). A VERSION+1 class must redeclare
  `schema_version: int = N`: `register()` refuses it otherwise (round 1).
- L7: pass `rules=` to `register_payload`, read them with `REGISTRY.rules(name)`. L8: `all.py` calls `REGISTRY.freeze()`,
  maps `GateError` size to 413 and the other stages to 422, and owns `docs/schemas/` (`export --check` is red until it exists).
- E0 / CN-1: import `extract_json` and `close_json` from `sutra_app.library.replies`; do not copy them.

## Mutation check
459 mutants (comparisons, constants, swapped arguments, dropped checks and error branches, early returns, widened
types) over the six modules: 451 killed. The 8 left are equivalent: nested `Annotated` is flattened by typing, pydantic
accepts a field by name or alias, `json.dumps` writes int keys as strings, two bounds that a pattern already enforces,
an upgrade chain of zero steps. Every survivor found on the way became a test.

## Review round 1
Seven confirmed findings, all fixed in L1's own files; every fix has tests that fail on the old code. 586 tests now (444
before), 2.3 s. Some statements above are superseded by this section; the lines they changed say so.
1. **Replies** (`replies.py`). A reply longer than `MAX_PAYLOAD_BYTES` (characters for text, bytes for bytes) is
   `ReplyInvalid("not_json")`, violation `reply_too_large`, before any pattern runs. The cubic `re.fullmatch` that read a
   reply made of one code fence is `_fenced_inner` (slicing). `extract_json` runs J2's fence pattern only up to the LAST
   `}\s*```` in the text, so it is linear: J2's search took 3.4 s on 16000 x "```{"; now 4 ms for 20000, 53 ms at the cap.
2. **`TRANSPORT_OPTIONAL` is per class.** `_TransportSchemaGenerator` writes each model's own set on its schema node as a
   private key that `_clean` reads for that object's `required` and strips, so a name is optional only in the class that
   lists it (no lookup by definition name: pydantic renames definitions that share a name). A subclass inherits its base
   class's set. Re-checked against J2: with J2's set on J2's `Artifact` (all 39 classes under the 19 section and 5 document
   models derive from it), `transport_schema`, `reply_schema` and `schema_sha` are J2's byte for byte.
3. **`verify_refs` never passes by looking at nothing.** `RegistryError` `specs_unbound` (nothing given or bound, or the
   loader returned None), `specs_empty`, `arity_unbound` (a spec holds a check and no arity function is known). `[]` means
   at least one spec was looked at; `check_arity=lambda name: (0, 99)` says "reply references only".
4. **Rules 3 and 7.** `base.unbounded_fields(cls)`: `Class.field` for each `str` or `list` with no bound, in `cls` and the
   classes nested in it (`[]` after a name: the items of a list; `{}`: the values of a dict). A pattern bounds a string only
   when anchored at both ends with a finite width; `JsonObject` is not looked into. `base.aliased_fields(cls)`: (class, alias)
   for each alias that is not a Python keyword. Tested on `Violation`, `DomainEvent`, the id types and toy classes.
5. **Gate, dict payload.** `_jsonable` walks any Mapping (nested too) into a dict and refuses what JSON lacks instead of
   converting it: a tuple, a key that is not a str, a container that holds itself: `shape` / `not_json` with the path.
6. **`DomainEvent.data`** must hold `EVENT_DATA_KEYS[type]` (design 13); more keys are allowed.
7. **`register()`** refuses a class whose `schema_version` default is not its VERSION (`bad_schema_version`).

Decisions and deviations of the round:
- `extract_json` is no longer J2's text line for line. Rejected: the verbatim function behind a size cap (80 KB of "```{"
  is far under any sensible cap and still took 5 s). The new one is tested against J2's own code (exhaustive over a 6-token
  alphabet up to length 5, 20,000 random texts, 17 awkward ones): same value, or same exception type and message.
- The reply cap counts characters of a `str` and bytes of bytes, like the gate's first check. `verify_refs` raises
  (a wiring mistake, like the other `RegistryError` codes) rather than returning a `Violation`.
- Tests changed because the finding says the old behaviour was wrong: `test_domain_event` (valid `data`), the nested-optional
  test (a nested required name stays required), and the `verify_refs` tests that expected `[]` for "nothing to check".
- Known limits: `unbounded_fields` reads Python's private regex parser (`re._parser`), and anything it cannot read counts as
  unbounded; a dict payload now costs a Python walk, about +25 ms at 1 MiB.

Not done here (needs files L1 does not own):
- Finding 3: the L6/L10/L8 package texts should say who binds (`REGISTRY.bind_function_specs(load_function_specs)`;
  `bind_check_arity(...)` from the check names of L4/E8), and L8 needs a test that its full-registry `verify_refs()` call
  checked a non-empty spec set. Until then those calls raise, which is the point.
- Finding 2: L7 sets `TRANSPORT_OPTIONAL = frozenset(OPTIONAL_FIELDS)` once on its Artifact base class, and every nested
  class of the artifact models derives from it (as J2's do), or J2's shas move.
- Finding 4: L8 runs both helpers over the full REGISTRY: `for family in REGISTRY.families(): for version in
  REGISTRY.versions(family): for cls in set(REGISTRY.kinds(family, version).values()):`, expecting `unbounded_fields(cls) == []`
  and `aliased_fields(cls)` within the allow-list `{("AtomView", "schema")}`.
- Finding 6: the stores and L4 (`Transition.events`) build events with the listed keys; `DomainEvent(data={})` now fails.

Mutation check of the round: 112 hand-made mutants of the new code (bounds and comparisons, dropped branches, swapped
arguments, widened types, message texts, the old cubic and quadratic code put back). 109 are killed. Of the first 100, 16
survived and 14 of those became tests (a pattern anchored at one end only, a width at the parser's cap, `oneOf` and `allOf`,
a field named by its Python name, an alias held by `.alias` alone, the 8-key and 40-character cuts of an event message, the
refusal texts, the edges of `_fenced_inner`, the exact limit message); a second batch of 12 added two more tests (characters
versus bytes, event shapes that cannot be changed). The 3 left are equivalent: `str()` and `repr()` of a pydantic alias
dataclass are the same text, a mutant that only adds `False or`, and a nested model dumped by name instead of by alias
(every library class reads both).
