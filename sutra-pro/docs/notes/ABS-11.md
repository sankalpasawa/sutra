# ABS-11 as built

`scripts/audit_old_templates.py --old <sutra-ui> [--dry-run|--apply] [--data-dir D]`: reads the old `function-templates/`, `artifact-templates/`, `engine-templates/` as data and prints what Pro covers and lacks. Measured against the real old folder: 15 function templates (5 covered: the `default` of each function; the 10 `money-movement` and `product-build` use-case variants lack a Pro equivalent), 10 artifact templates (none matches a Pro artifact type by name: the old ones are department-level files like brief and request, Pro's are document types like prd and hld), 6 engine templates (none matches J2's template folders).
Deviation from the spec: Pro has no registry these seeds could be added to through the library write gate (Pro's function specs are one per function and its artifact and engine templates are J2's), so `--apply` makes a verbatim copy of each lacking seed that passes a shape check (id, name, version) into `<data-dir>/library/old-templates/` and prints the warnings; nothing in Pro reads that folder yet (LATER: offering a use-case template to a team). The old folder is never written (a test proves it byte for byte).
