## What it does
- `finish.run_steps(host, status)` runs after `publisher.stop()` and before `heartbeat.stop()` in `Host._conclude`, so the heartbeat still beats while the steps work and the
  final publish and `run.ended` come after every file they write. It does nothing unless the run ended `done` or `done_with_open_items` (a stopped or crashed run gets no step and
  no file). The seam is two added lines in one hunk (the local import and the call); `loop.py` is otherwise unchanged.
- Steps, in order, each guarded:
  - `agent_views`: `j2_agent_views.build(<run folder>, quiet=True)`: `agent/*.json`, `agent/audits/A-n.json`, `artifacts/<name>.json`, `site/sections/<id>.json`, the stamped
    `prd.json`, `hld.json`, `lld.json`, `design.json`, and `<output>.json` for a document-flow output (a project run gets `project.json`). Trace: `files`, `valid`, `invalid` (up to ten paths).
  - `catalog`: `j2_template_lib.collect(<team runs folder>, runs=[<this run>])` inside `j2_template_lib._library_lock()` (P10). Skipped, with the reason in the trace line, when the
    engine setting `template_library` is off, when the run is a mock run (D142), when the run folder holds no `templates.json` (refinement: nothing to collect, so the library is neither
    locked nor rewritten) and when the lock stays taken for its whole wait (`LibraryBusy`, 30 s). Trace: `added`, `renumbered`, `same`, `not_recorded`.
- The guard: an exception, a `SystemExit` (`j2_agent_views.build` raises one for a folder that is not there) or a step that took more than 10 s is one `finish.step` line in
  `trace.jsonl` and never a failed run; a step over the limit also ends the rest ("<step> took more than 10 s"). The limit is checked when a step returns: a step is never cut short from
  outside, because that would leave a half-written file. No step starts once the process was asked to stop. `KeyboardInterrupt` is not swallowed.
- Trace line: `{"step", "result": "ok" | "skipped" | "failed", "seconds", ...facts, "why" | "error", "slow"?}`, one per step, also for a skip.
- `finish.py` imports no J2 module at import time (the host sets J2's environment before J2 is first imported, and `loop.py` imports `finish` only inside `_conclude`); a test
  imports it in a clean interpreter and checks that no `sutra_app.engine.j2*` module came with it.
