- `scripts/j2_diff_of_record.py`: the standing, two-way difference between the folder `prototypes/j2` (an extraction of it, or the tool's own `git archive` of a commit) and Sutra Pro as committed. It classifies every J2 file (vendored: named in the Files table of VENDORED.md; page: written by `port_j2_ui.py`; legacy test copy; excluded with a reason from a table in the script; unlisted; undecided), runs `vendor_j2.py --check` and `port_j2_ui.py --check` as subprocesses and shows what they say (a build that stops is reported as that), and prints a markdown report. `--check` exits 0 only when both checks pass and every file is decided. Classification only: equality is the two scripts' `--check`.
- `docs/notes/J2-DIFF-OF-RECORD.md`: the report before sync 4 (real scripts, plus a throwaway copy of the vendor script with two anchors fixed for the counts), the report after it (real, `--check`, exit 0), the exclusion table, and where its reasons disagree with the other records.

## Decisions (where the brief left a choice)
1. A `patched` status rests on the J2 sha256 that VENDORED.md records (a record inside Sutra Pro as committed), not on any other reference; the verdict is the two checks.
2. A generated page file is `patched` only while the port check passes, else `unverified` (the port stops at the first drift and says nothing per file). Legacy copies are `edited`, never compared by bytes; the report gives the number of J2 lines the copy lacks (flow test 1,555; the others 2, 3 and 5).
3. `--check` also accepts the generated page files as decided (the brief's list names three classes; the page is the fourth in its own item (a)).
4. `vendor/*` is class `page`, not excluded: `port_j2_ui.py` carries it to `sutra_app/ui/static/vendor/`, which `ui/routes.py` serves at `/ui`.
5. The vendor script's informational `note:` line (it names the script's own built-in baseline) is counted, not repeated; failures are always shown.
6. The two scripts get `--dest` and `--root` explicitly (a copy elsewhere would otherwise default to the wrong folder), and `--commit` only when `port_j2_ui.py --help` lists it. `--vendor-script` and `--port-script` take a copy for a dry run.
7. The real-repository test settles by VENDORED.md: strict once it names the commit (now), an expected failure with the list before (while the table described another J2).
