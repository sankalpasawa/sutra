## Decisions and deviations
1. The five POSTs and the PUT are `async def` that read the body by hand and run the work in the thread pool (`run_in_threadpool`), not plain `def`: a
   body that is not a JSON object is J2's 400 `{"error":"bad json"}` (FastAPI would send its own 422). GETs are plain `def`.
2. `serve(services, view, request, dept, extra, ...)` takes the path parts as a mapping (a path part may be called `name`).
3. Errors: J2 routes keep J2 bodies (`{"error":"dept_required"}`, `{"error":"not_found"}`); `read_only` and everything on the two settings routes use
   the envelope. On the settings routes a malformed `?dept=` is 422 `validation` (dept is optional there), an unknown one 404 `not_found`.
4. The token dependency is a route dependency, so it runs BEFORE the team lookup (401 beats 400/404). An archived team's settings PUT is 403 too.
5. Current run = `resolve_run(None, dept)` unless its id is `<=` `page.json.since_run` (string compare: run ids sort by time). `live_id` of `/api/runs`
   is that run's id or "". A current run without `snapshot.json` yet (host starting) is shown as idle. A `ref.dir` that does not name an existing folder
   `departments/<dept>/runs/<ref.run_id>` is treated as missing. A ref of another team from `resolve_run` is not believed.
6. `say` clears `next_settings` only when the delivery says `follow_up` (a new task); `Busy` is recognised by `code == "busy"` or a class named
   `Busy`/`FakeBusy` (the engine does not import the orchestrator); any other error is a 500. `output` outside idle is 409 `{ok:false, output:<run's>}`;
   an unknown type falls back to `website` like J2. `reset`: `stop_live` False is 409 and touches nothing; True writes `since_run` = latest run id.
7. Settings: `effective` = defaults < `data/engine.json` < the team's file; the server's `J2_*` env is not a layer (a spawned engine never gets it).
   `global`/`department` are `{}` when the file is missing. PUT: strict check of the new values, `true` refused for non-flag fields, the whole file
   re-validated, no write when nothing changes, temp file + rename, 0600. An unreadable or invalid file is 422 naming the file (GET and PUT).
8. The idle page's settings fall back to J2 defaults when a settings file is broken, so the page still draws.
9. The tests use FastAPI 0.162 lazy routers: tests read the route table from `app.openapi()["paths"]`; the app in tests sets `openapi_url=None`.

## Known limits
- Headers are added to every response the engine's handlers make (errors included), not to the framework's own 404/405/422 or the orchestrator's 401 envelope.
- Redaction is text level, after JSON encoding (as J2): a secret that JSON escapes (a quote, a backslash) would slip through; `Redactor.scrub` on
  data would fix it but `services.redact` is `str -> str`.
- `idle_snapshot` builds a throw-away `J2Run` per idle poll (about 700 ms apart); no cache.
