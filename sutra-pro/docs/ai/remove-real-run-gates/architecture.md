## Approach

Delete the gates and keep one straight path: when the rest is workable, `_goal_done` runs the next done workflow's real run directly (no card, code or pause), diffs its `folder` before and after, fails its items on an `expect` mismatch or lets Audit judge them, writes the row, and goes on. Package installs happen inline where the build used to pause. A single helper, `_real_run_open()`, lists every required real run that has not passed; `_goal_done`, `_ship_outcome` and `_write_summary` use it so no ending can say "Done:" while one is left.

## Alternatives considered

| option | why rejected |
|---|---|
| Keep every existing patch edit and add P46 edits that undo them at the end | adds text then deletes it; anchors on anchors; more lines, not fewer. Rejected for the rule "delete code" |
| Keep the row's gate keys with fixed values (`approved: true`, `code: null`, `dry_run: {}`) | founder Q-2: never write `approved: true` when nobody approved; the keys have no reader once FR-4/FR-6 land |
| Network option a (no srt for the real run) or c/d (wrapper, sandbox-exec/bwrap) | founder chose b; a loses the write limit (FR-30); c and d are new code per platform |
| Guard "Done:" only in `_goal_done` | the deed, chain and ship endings (j2.py:5901, :6510, :4406-4414) would stay open; `_write_summary` is the one place every ending passes |
| Mark "already ran" only in memory (`real_runs_done`) | a follow-up restores workflows but not that dict, so it would run a parent's real run again, unasked (C-19) |

`_real_run_next(r)`:
1. `w` = first workflow with `real_run`, status `done`, `not self._ran_real_run(w["id"])`; none → False.
2. `if self._env_stops_real_run(w, rr): return True` (FR-9; unchanged logic, reworded).
3. `before = _tree(folder)`; `res = real_run(...)`; `diff = _tree_diff(before, _tree(folder))` (folder realpath; reads are not recorded).
4. `mm = expect_mismatch(rr["expect"], diff) if res ran and exit 0 else ""`.
5. `judged = {}` if `mm` or not (ran and exit 0) else `_judge_real_run(w, res, diff, mine)` (P33).
6. `audit` key: on `mm`, `{n: {"verdict": "NEEDS_REVISION", "evidence": "not what it said it would do: " + mm}}` per checked item; else P33's.
7. Row (FR-27); post "Ran for real: ..." (or the evidence); `_event`.
8. `ok = ran and exit 0 and not mm`; `real_runs_done[wid] = ok`; `real_run_item_ok` from `judged` (and `False` per item on `mm`); `real_run_why[wid]` = `mm` text, the evidence, or Audit's evidence of the first failed item, when not all pass.
9. Update the last audit's results for the items (as j2.py:6376-6386 today; NEEDS_REVISION with the mismatch note on `mm`).
10. `self._goal_done(r)`; return True.

`_real_run_open()`: for each workflow in `self.workflows` with `real_run` whose `checks` still name a done-when item: met when some workflow checking that item has `real_runs_done[id] is True` and `real_run_item_ok.get(text, True)`; otherwise "has not run" if `not self._ran_real_run(id)` and `id not in real_runs_done`, else "did not pass: " + `real_run_why[id]` (or the row's evidence when the why is unknown, as in a follow-up). One line per workflow.

Outcome rules (FR-40):
- `_goal_done`: `open_rr = self._real_run_open()`; when non-empty the outcome is `"Done with open items: " + "; ".join(open_rr) + "."` plus `" Still not workable: ..."` when `rest + opened` is non-empty. Replaces the `rr` expression at j2.py:7351-7356 and the P44 "Left out" line.
- `_ship_outcome`: `fails += self._real_run_open()` in place of `_real_run_pending()` (no double listing: `_real_run_pending` lines are a subset).
- `_write_summary`: before `status`, `if o.startswith("Done:") and (x := self._real_run_open()): o = self.outcome = "Done with open items: " + "; ".join(x) + "."`. The net for every other ending.
