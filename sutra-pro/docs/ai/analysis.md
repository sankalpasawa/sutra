# Repository analysis (sutra-pro, UI and run-file serving slice)
Last updated: 2026-11-25 at commit f21add06

Scope: this covers the parts of `sutra-pro/` that the team page's Simple view ("Studio") and its run-file routes touch, plus how to build and test them. It does not map the whole repository.

## Stack
- Python >= 3.11, FastAPI >= 0.162, uvicorn, pydantic 2 (pyproject.toml [project]). Version 0.8.3.
- Dev: pytest 8, pytest-timeout (600 s per test), pytest-rerunfailures, httpx, websockets, pyyaml (pyproject.toml optional-dependencies.dev).
- UI: plain browser JS with no build step. The team page is one generated HTML file, sutra_app/ui/pages/j2_ui.html (4,821 lines), plus Sutra modules in sutra_app/ui/static/js/. JS unit tests run on `node --test` (at least node 20, tests/ui/test_node_suite.py:22).
- Desktop: an Electron app in desktop/ (desktop/README.md).
- Engine: J2, vendored from prototypes/j2 at a pinned commit by scripts/vendor_j2.py with numbered patches P-n (sutra_app/engine/VENDORED.md).

Direction: the page calls /api/*, /view, /site/* and /file/* → engine/api → engine/views.py → j2_artifacts, j2_studio, j2 → the run folder. The UI package does not import the engine.

## Main code paths
1. Simple view: poll /api/state (j2_ui.html:1965) → renderSimple (:1222) → sTop (:1288), sViews (:1340) → sTabs (:1326) → sLoad (:1359) into the sandboxed #sframe/#sframe2 (:58); the team tab is sTeamwork (:1600); the finish bar is sFinish (:1124), drawn at :1244.
2. Deliverables: sArts (:1697) → /api/artifacts → views.artifacts (views.py:521) → j2_artifacts.listing (j2_artifacts.py:184), which reads artifacts.json or scans by types.json globs (rows, :118-180).
3. A file as a page: /view?name= → views.view (views.py:625) → j2_artifacts.served (:197; allow-list and 2 MB cap) → view_page (views.py:574).

## Conventions
- Decisions: "## D<n> — title" in docs/DECISIONS.md plus docs/diagram/decisions.json; tests/test_diagram_decisions.py enforces both.
- Commits: "SUT-<n>: D<n> <plain sentence> (patch/edit ids)".
- Comments are long plain sentences that cite D numbers. Sutra page modules are IIFEs that adopt page globals (avatars.js:190-205).
- No home paths or owner names in tracked files (tests/test_ownership.py, D99).

## Risks and hotspots (6-month churn)
1. engine/j2.py: 81 commits, 958 KB, vendored and patched; SUT-28 is changing it now.
2. ui/static/js/home.js (66) and ui/static/css/sutra-panel.css (46).
3. ui/pages/j2_ui.html: generated. A hand edit fails test_port_edits.py or the next re-port; a change to J2's own render shifts the goldens in tests/ui/fixtures/j2/golden-*.json.
4. DECISIONS.md (141) and decisions.json (84): decision numbers collide across parallel branches.
