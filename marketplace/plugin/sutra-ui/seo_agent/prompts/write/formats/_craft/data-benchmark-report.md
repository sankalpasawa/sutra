# data-benchmark-report — wrap rules (read by the wrapper step)

## Intro
- 2 to 4 sentences that state the evidence base immediately: what was gathered, from which kinds
  of published sources, why it matters now. Describe the sources honestly — we compile published
  figures, we do not run surveys. Never imply original research.

## TL;DR
- The two or three findings the whole page turns on, each as a full statement a reader could
  cite. This block is the citation bait; make each line quotable on its own.

## Close and takeaways
- Close with the takeaways plus a ready-made "cite this" line, so a writer can lift the reference
  in one copy-paste.

## FAQ
- Nothing specific to this format.

*Publishing note (not the wrapper's job): this page ships as a free web page, never a gated PDF —
a form kills the citation.*
