# comparison-rankings — wrap rules (read by the wrapper step)

## Intro
- Verdict first, in at most 200 words: name the "best for most" pick in the first paragraph, and
  say who the page is for and how the options were scored.
- For a "which is better?" query, the top answer sits in the first 60 words.

## TL;DR
- The verdict block: the best-for-most pick, then one line per strong alternative with the use
  case it wins ("pick X for high-volume screening"). No number soup.

## Close and takeaways
- Close with a plain "pick A if…, pick B if…". The body's deep dives argued it; the close settles
  it in the reader's own decision terms.

## FAQ
- Questions comparing two named options, or asking what a scored dimension means, beat generic
  category questions.
