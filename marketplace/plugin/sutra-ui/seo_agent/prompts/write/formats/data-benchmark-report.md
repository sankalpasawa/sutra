# data-benchmark-report

Used by ONE consumer: the architect's shape step (it becomes {{FORMAT_STRUCTURE}} in the structure prompts).
Rules about the intro, the key-findings menu, the close and the FAQ live in `_craft/data-benchmark-report.md`
and are NOT injected here.

## Structure (the format's signature)
- [ ] **Big-number headline** — leads with the single biggest number or the dataset scale, never a neutral label. If you can't imagine a compelling headline for a finding, the finding is weak.
- [ ] **8-15 distinct findings, one section each** — no two overlap; each carries its own number.
- [ ] **Segment findings** (industry / size / region) so one study feeds many citers.
- [ ] Front-load the crunchiest bite-sized stats.
- [ ] **OPTIONAL — a provenance section, where the numbers came from.** Include it only when this article's figures come from several sources or several editions of the same source, which is when a reader genuinely cannot tell them apart. It states, for each headline figure: which publication and which year it comes from, and what stops two of these figures being compared directly (a changed method, a different sample, an average against a median). It is NOT a description of research we conducted — we did not run a survey, and the article must never imply we did.
