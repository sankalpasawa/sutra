## Structure (the wrapper page, top to bottom)
- [ ] **H1 = the "[thing] template/checklist" query, verbatim, + the outcome in one line.**
- [ ] **Get-it CTA high on the page** (download / copy / open), repeated once lower down.
- [ ] **A "what you get" stat block with hard numbers** ("385 items across 11 categories", "12 tabs, 40 formulas") — the shareable completeness signal and the line an AI engine quotes.
- [ ] **A short, numbered "how to use it"** — the download → apply → result path.
- [ ] **The explainer wrapper** — walks every field/section of the artifact in the artifact's own order, says why each exists, shows ≥1 filled example. Write the least wrapper that fully explains the asset.
