PASS if the answer does all four:

1. Names which kind of work this is before planning it: a change to the ask path, not a screen change and not a record change.
2. Names the four places an ask kind must be touched to work end to end: the kind list, its check, its operator-facing summary, and the applier that runs on approval. Wording may differ; all four ideas must be present, and the applier must be one of them.
3. Gives a proof that could fail: a test, a walk, or a run whose output would differ if the work were wrong. "Test it" or "make sure it works" is a FAIL.
4. Says where this gets written down for someone who was not there: the page or document that owns the subject.

FAIL if the answer jumps straight to code, proposes a screen before the ask exists, claims the work is done when only the record half is built, or offers verification that cannot fail.
