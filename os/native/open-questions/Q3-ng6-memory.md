# Q3: NG6 — memory as a primary claim

## Question

Verbatim per §14.10 row Q3 (post-2026-05-09 ratification): the row records the resolved answer in place of an open prompt. The original question shape was: is "Native is a memory product" a claim Native should make (compete with Mem0/Composio category), or disclaim (memory is substrate; Native is governance + emergence)?

## Why it matters

Positioning against the memory category is a category-defining decision. Claiming memory-product status places Native head-to-head with Mem0/Composio/Bond/Donna competitors and dilutes the governance + multi-tenant + emergence + audit + closed-loop story. Disclaiming it lets memory products integrate as substrate while Native owns the higher-leverage layer.

## Default if unanswered

n/a — answer is recorded in canon row directly; no fallback default applies once ratified.

## Answer

**Disclaim NG6**: "Native is NOT a memory product." Memory is commoditized substrate. Native's distinguishing claim is governance + multi-tenant + emergence + audit + closed-loop artifact discipline (§14.6 NG6, §13.2). Mem0 / Composio / similar memory layers integrate via the Native **Connector** primitive — Native consumes their memory surface, does not compete with it.
