# Q10: TAM segment — founder-portfolio v1 vs any-manager-IC v1

## Question

Verbatim per §14.10 row Q10 (post-2026-05-09 ratification): the row records the resolved answer in place of an open prompt. The original question shape was: does v1 target the founder-portfolio narrow wedge, or any-manager-IC broader TAM?

## Why it matters

TAM choice is the GTM trigger for everything downstream — pricing tier (Q6), onboarding fidelity, support model, content surface, churn cohort, retention math. Going narrow first means faster iteration on a tight-feedback cohort. Going broad first means slower iteration but bigger pipeline.

## Default if unanswered

**v1 ships for the narrower segment; v2+ expands once v1 PMF signal lands** (per §14.10 row Q10 "Default if unanswered" column).

## Answer

**Founder-portfolio v1 wedge.** "Any manager-IC" is a v2+ TAM expansion. v1 ships for the narrower segment; v2+ expands once v1 PMF signal lands per Q7 trigger (≥3 T4 green 14d OR ≥1 T2 blocked on upgrade).
