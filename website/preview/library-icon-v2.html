One goal with one check that flips. Everything a department does is one of these, whether you wrote it, a function proposed it, or an engine opened it on a run.

A work atom names what must be true when it is finished. These are the ways of working it may draw on: the ones it declares when it opens, and the ones it used when it closes. A declared skill never refuses anything, because refusing is a rule's job.
