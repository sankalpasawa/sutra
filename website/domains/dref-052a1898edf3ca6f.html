D1.4Build & Structure Guards

Guard WHERE things land: layer declarations, structural moves, boundaries, permissions, new paths, foundational edits.

D1.5Feedback Loops

Capture and route operator feedback signals (corrections, overrides, abandonment) to the canonical channel.

D1.6Session Lifecycle

Fire on SessionStart/UserPromptSubmit/Stop to set up, checkpoint, banner, rotate, and tear down session state.

D1.7Telemetry Collectors

Record measurements ONLY (latency, estimates, triage, counts, time). Never block, never audit — collection is the whole job.

D1.8Compliance Sensors

Audit whether governance/process state is compliant (health, policy coverage, phase exits, graduation). Never collect raw metrics, never block mid-turn work.

D1.9Runaway & Egress Guards

Stop runaway loops and secret/key egress; recover from crash states. Mechanism-defined: loop budgets, env-key scans, resilience.

D1.10Token Efficiency

Compress voluminous tool output before it costs context (bash summaries, RTK rewrite, MCP compression).

D1.11Dispatch & Routing

Route post-tool events and subagent dispatch: briefs attached, completions checked.
